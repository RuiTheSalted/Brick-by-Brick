# Brick-by-Brick


We have five main folders; assets, maps, menus, scripts, & ui.
Below is an explanation on what goes on in each. 
Note: Imagine ":" as a folder/another layer.

Assets - Here we would store the following
	Sprites (art):
		Balls
		Bricks
	Audio:
		Music
		SFX
	Fonts

Maps - Here we would have the following
	Map Difficulty:
		Easy:
		Medium:
		Hard: 
			"Map Name":
				Changes "Map Name" undergoes.
	Obstacles used for Maps

Menus - Here we would have the following
	Title Screen
	Settings on Main Screen:
		Everything inside Settings
	Map Select Screen
	Character Overview

Scripts - Here we would have the following
	All the Logic & Physics 

UI - Here we would have the following
	HUD:
		Selectable Balls
		Currency
		Etc...
	Pause Button:
		Audio Levels
		SFX Levels 
		Other Screens that show up
	Start Button
	Upgrades Menu: 
		Upgrade for Specific Ball
	Overlays
